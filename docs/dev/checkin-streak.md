## 已定

金额、天数、补签卡仍按积分准则，不改：

| 点 | 决定 |
|---|---|
| 每天 | +10，流水 title `签到` |
| 连续恰好第 3 天 | 再 +20，流水 title `连续签到奖励`；送 1 张补签卡 |
| 连续恰好第 7 天 | 再 +50，流水 title `连续签到奖励`；送 1 张补签卡 |
| 第 8 天及以后 | 只要不断，每天仍只 +10；不再给第 3 / 7 那种额外积分和卡 |
| 补签 | 只 +10，不触发连续额外，不送卡 |
| 断签且未补 | 连续归零，下一次算第 1 天 |
| 合同 | **不改。** 进度条用已有 `streak` + `today_checked` 在页面算，不加字段 |

发分已实现。本包只补签到页上的「近 7 天」进度，并改种子方便点验。

### 为什么是进度条不是周历

国内内容 / 积分 App 连续加码的主流是 **第 1 天 … 第 7 天** 一排节点（已签浅底，大奖天标更高积分），不是周一到周日。月历用来看哪天签过、点哪天补签。两套并存：上面进度、下面月历。

不做 7 张大卡片（和月历叠在一起太高）。不做节点之间的连线（Skyline 用 flex 七列即可）。

### 签到页（本包只加框起来的那一块）

```
连续签到 N 天          补签卡 x 张

┌ 第1  第2  第3  第4  第5  第6  第7 ┐
│ +10  +10  +30  +10  +10  +10  +60 │
│           补签卡              补签卡 │
└─────────────────────────────────┘

‹  YYYY年M月  ›
[ 月历，已有，不改规则 ]

[今日签到] 或 「今天已经签过了」
```

- 七个圆点横排。普通天圆点里或正下写 `+10`；第 3 天 `+30`；第 7 天 `+60`（当天合计，不要拆成「+10 再额外」）。第 3 / 7 天再标 `补签卡`。
- 已走过的天：主色浅底。今天未签时，**下一档**（`streak + 1`，且 ≤ 7）描边，表示「签了就到这天」。
- 第 8 天及以后：七格全填满，没有第 8 格，也不新开一轮第 3 / 7。
- 进度条不可点。今日仍只点底部「今日签到」。
- 文案用「第1天」…「第7天」，不要「周一」。

已走天数：

- 今天已签：前 `min(streak, 7)` 格填满。
- 今天未签：前 `min(streak, 7)` 格填满（连续算到昨天）；下一格描边。
- `streak === 0`：全空，第 1 格描边。

### 签到成功提示

`wx.showToast` `icon: 'none'`（不要 success 图标，字会被截）。

| 情况 | title |
|---|---|
| 普通天 | `签到成功，积分 +10` |
| 第 3 天 | `积分 +30，补签卡 +1` |
| 第 7 天 | `积分 +60，补签卡 +1` |
| 当天已签 | `今天已经签过了`（已有） |

用接口返回的 `extra` / `awarded` / `makeup_cards_awarded` 分支，不要前端自己猜第几天。

### 种子

方便点一次就碰到第 3 天：

| 项 | 值 |
|---|---|
| `checkin_dates` | 昨天、前天（本地自然日）。**不要**包含今天 |
| `makeup_card_count` | **0**（点今日签到后应变 1，才能看出送卡） |

不要把「今天」写成已签。不要为了演示第 7 天再改种子。
