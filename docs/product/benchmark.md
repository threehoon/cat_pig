## 验收（功能对等，不是 UI 对等）

用户在我们小程序里能完成与截图相同的事：

1. 打开首页：看到四个入口和一条广场动态。
2. 上传一组相册（标题、说明、标签），在相册 tab 看到。
3. 选 2–9 张图提交图生视频，任务列表出现一条「待执行 / 执行中」。
4. 发一张帖（可草稿），在广场看到；详情能关注作者、点赞、评论、收藏、转发。
5. 签到一次，积分流水多一条；余额能在积分明细看到。

不验收：对方品牌名、插画、像素级布局、积分具体数值与对方一致。
