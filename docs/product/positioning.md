# 产品定位与对标

## 一句话

在微信里做 **宠物内容小程序**：自己的相册、把照片做成短视频、在广场看别人晒宠和提问。不是私人日记账本。

## 对标对象（已锁定）

**「萌爪日记」同类产品**（用户提供的界面截图，2026-08-24）。

- 依据：首页、图生视频、广场 / 论坛、发帖、相册上传、积分明细、任务管理等截图，见 [reference/](reference/README.md)。
- 对的是 **产品类型和功能清单**（入口、底栏、相册独立上传、AI 图生视频、广场发帖、积分 / 签到 / 生成任务）。
- **不使用**对方品牌名、插画、文案原句；界面用自己的暖米色 + 橙色，不像素级抄。
- 工作标题仍用 **「宠物记录」**（正式品名未定）。

功能逐条对照见 [benchmark.md](benchmark.md)。优先级见 [capabilities.md](capabilities.md)。

| 波奇 / 宠胖胖 | 电商 / 内容平台 |

## 学什么

1. 打开就是门户：顶图、四个入口（图生视频、相册、论坛、签到），下面接广场动态。
2. 底栏五个：首页、相册、中间「创作」、论坛、我的。中间加号进图生视频。
3. 相册是独立上传（标题、说明、标签，可选同步到论坛），不是日记的副产品。
4. 图生视频：2–9 张图 + 提示词 + 分辨率，扣积分，生成过程在「任务」里看状态。
5. 广场 / 论坛同一套帖子：板块（问答、晒宠、分享、求助、日常、经验）、关注、点赞 / 评论 / 收藏 / 转发、发帖可存草稿、发布后审核。
6. 积分：发帖、签到、注册等获取；生成视频消耗。我的里能进明细和任务。
